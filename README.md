Sistema web de loja desenvolvido em **PHP, MySQL e JavaScript**, com foco em operações CRUD e testes automatizados com **Selenium**.

O projeto permite cadastrar, editar e excluir produtos, além de selecionar itens da loja, definir quantidades e adicioná-los ao carrinho de compras. O carrinho utiliza sessões PHP para armazenar os produtos e, ao adicionar o mesmo item novamente, a quantidade é somada automaticamente.

Também foram implementados testes automatizados com Selenium em Python, simulando ações reais do usuário, como selecionar produtos, informar quantidades, adicionar itens ao carrinho e navegar entre as páginas do sistema.

### Tecnologias utilizadas

* PHP
* MySQL
* HTML
* JavaScript
* Python
* Selenium
* XAMPP

Projeto desenvolvido como atividade acadêmica da disciplina, com o objetivo de praticar integração com banco de dados, operações CRUD e automação de testes em aplicações web.
